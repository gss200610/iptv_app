# AI Memory — IPTV Player

Memória persistente do projeto para agentes de IA (Cursor, Claude, Codex) e para quem continuar o trabalho em outro computador.

| Arquivo | Conteúdo | Quando atualizar |
|---|---|---|
| [PROJECT_STATE.md](PROJECT_STATE.md) | Visão geral, decisões arquiteturais, funcionalidades, arquivos, testes, problemas conhecidos e backlog | Sempre que uma funcionalidade, decisão ou problema conhecido mudar |
| [HANDOFF.md](HANDOFF.md) | Estado da última sessão e o passo exato para continuar | Ao final de cada sessão de trabalho |

## Regras para agentes

1. Leia `HANDOFF.md` primeiro e depois `PROJECT_STATE.md` antes de alterar qualquer coisa.
2. Ao terminar uma sessão, reescreva `HANDOFF.md` (não acumule histórico nele) e atualize as seções afetadas de `PROJECT_STATE.md`.
3. Nunca grave URL do servidor, usuário, senha ou dados da conta IPTV do usuário nestes arquivos.
4. Datas no formato AAAA-MM-DD. Arquivos em UTF-8.
